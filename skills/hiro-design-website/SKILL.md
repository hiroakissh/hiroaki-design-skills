# 内容に合うWebサイトを作る

何を誰に伝え、読んだ人に次に何をしてほしいかを確認する。既存サイトなら内容・ブランド・良い点を観察する。[個人方針](references/profile.md)、[配色](references/colors.md)、[制作の判断](references/craft.md) を使う。

## 構成と表現

- 最初に、内容を具体的に伝える見出しと、理解を助ける製品・作品・情報を置く。
- 第一画面の主な行動を明確にし、説明、根拠、詳細、次の行動へ読み順をつなげる。
- 文字、図、実際の製品画面など、内容の特徴を伝える表現を選ぶ。汎用の飾りや、意味のない大きな数値で埋めない。
- ライムは限られたブランド表現に使い、淡い背景の小さな文字や、成功の意味へ流用しない。
- 書体と文字サイズは、日本語と実際の文章量を見て決める。小画面では読み順を保ち、単に全体を縮小しない。
- 自動再生や入場アニメーションを足す場合は、伝達上の目的と動きの軽減設定を確認する。

具体的な構成の判断は [伝達と導線](references/communication.md)、操作は [表示・操作](references/accessibility.md) を参照する。

## 検証

実際に表示して、第一画面で主題が分かるか、リンク先が正しいか、モバイルで内容が欠けないかを確認する。根拠のない実績・推薦・価格・架空の顧客の声を、実情報として掲載しない。
