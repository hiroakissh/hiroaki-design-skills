# 伝達と導線

見出しは「何のサービス・作品・情報か」を伝え、説明文はその対象と価値を補う。主ボタンは行った結果を表す動詞にする。二つのボタンが同じ強さで競合していないかを見る。

セクションの数や順番は内容から決める。説明のための順序でないものに、装飾の連番を付けない。すべての内容を同型カードにせず、文章・比較・製品画面などに合う構成を使う。

画像は情報を加える場合に使い、既存の画像やコード表現で足りる場合はそれを使う。画像生成や外部サービスの使用は、依頼と利用可能な機能に合わせる。

仮データのサンプルでは、その旨を分かる場所に記す。実績値や推薦文の創作を、公開用の事実として扱わない。
