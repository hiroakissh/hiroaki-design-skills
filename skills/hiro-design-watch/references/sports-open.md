# スポーツ・オープン環境と旧SDK

出典と取得範囲は [索引](guide-index.md)。スポーツ画面・実装ライブラリ・操作マニュアルを、汎用アプリ向けHIGと同じ資料として扱わない。

## Garmin Connect IQ

目的からDevice App、Glance、Data Field、Watch Face等を選ぶ。運動中に既存画面へ情報を足すData Fieldと、独立した操作を持つアプリは別の面である。公式UX記事に記載される入力制約やAPI levelには世代差があるため、最新の対象機種・APIリファレンスでも確認する。

主要な値を最初に置き、Glanceから必要な詳細へ進める。タッチ対応を前提にせず、物理ボタンでの選択・戻るを対象製品で確認する。MIP/AMOLEDなど表示方式、少色パレット、メモリ・更新条件をデバイス仕様と照合し、OLED向けの黒背景を反射型表示へ機械的に強制しない。

## SuuntoPlus

公式Sports Appsは運動中の独立したワークアウト画面という利用範囲を示す。ボタン操作と、電話側で行う設定を区別する。一般的なWatch用ホーム画面や常駐ランチャーを実装できると解釈しない。

詳細な開発資料はSuuntoPlus Editorに含まれるという公開案内まで確認した。Editor同梱の全UI仕様は今回取得していない。実装時は同梱資料と対象時計を確認する。

## Pebble / Core Devices

公開design-and-interactionガイドを参考に、よく使う操作を先に置き、物理ボタンの意味をAction Barやメニューで示す。資料には旧SDKの記述が含まれるため、現在の対象デバイス・SDKとの互換性を再確認する。単色でも意味が残るようにし、色だけで情報を区別する古い提案を個人のルールへ取り入れない。

## Bangle.js / Espruino

Layout libraryは配置と更新の実装資料。モデル別の画面・入力とwidget領域を確認し、値が変わった部分だけを描き直す方式を検討する。全文字列の最大幅、長いラベル、単色・少色での判読を調べる。ライブラリを使っただけでアクセシビリティや電池寿命を検証済みとしない。

## PineTime / InfiniTime

公開Applications文書は既存アプリの操作例であり、共通HIGではない。サイドボタンや戻る操作、アプリを離れた後の処理を対象ファームウェアで確認する。他のWatchのバックグラウンド動作を移植できると推定しない。

## Fitbitと取得の境界

Fitbit Publishing Checklistは旧SDK向けの資料として保持する。未取得データ・権限拒否・機種差の確認に参考になるが、新規製品への対応や配布可否は別途確認する。現行Pixel Watchの設計根拠にはWear OS資料を使う。

PolarのBLE SDK、COROSのPartner API、Withings Mobile SDKは、確認した範囲では連携・同期・計測などの資料である。これをWatch画面のHIGや自由なWatchアプリ開発の証拠として扱わない。必要な機種のUI設計資料は未取得として残す。
