# 表示・操作の確認

- 意味に合う見出し、表、リスト、ボタン、入力ラベルを使う。見た目だけの要素を操作部品に見せない。
- キーボードで到達・操作でき、フォーカスが見えるようにする。モーダル等はフォーカスの移動と復帰も確認する。
- 色に加えて名称・記号・形を使う。アイコンだけの操作には理解できる名前を与える。
- 狭い画面、文字拡大、長い日本語、空・読込・失敗状態を必要に応じて確認する。重要な情報を省略する場合は全体を見る手段を用意する。
- 動きの軽減を尊重する。移動や点滅がなくても、操作結果と状態が伝わるようにする。
- 通常文字4.5:1、必要なUI図形3:1という色の確認は、アクセシビリティ全体の一部。計算だけでWCAG 2.2 AA全体の適合を宣言しない。
- 図表には単位・ラベル・要約または表を添える。資料の読み順と、書き出したページも確認する。

この文書は制作時の基本確認。詳細な監査が必要な依頼では、対象と検証範囲を明示して追加の確認を行う。
