# 一覧・入力の状態

| 状態 | 確認すること |
| --- | --- |
| 最初の空状態 | 何を入れる場所か、始める操作は何か |
| 検索結果なし | 検索条件と解除方法、データ自体がない場合との違い |
| 読込中 | 作業を二重実行しないこと、既存内容を保持できるか |
| 入力エラー | 対象の入力と修正方法、入力内容を失わないこと |
| 保存完了 | 行った操作と結果が同じ用語で分かること |
| 選択中 | 選択対象・件数・解除、チェックや文字の併用 |

独自の状態色はAtmospheric Graphite v1.0では未確定。フォーカスは既存の `focus`、エラーは `error` と説明文を使い、選択はチェックや文字などでも示す。新しい色を導入するときは、確定済みのパレットと区別する。
