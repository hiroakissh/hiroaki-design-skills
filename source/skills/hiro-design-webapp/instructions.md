# 作業しやすいWebアプリを作る

主な作業、データ量、利用頻度、画面の対象者、既存の実装を確認する。[個人方針](references/profile.md)、[配色](references/colors.md)、[制作の判断](references/craft.md) を使う。

## 情報と操作

- 一覧・検索・絞り込み・詳細・編集が、実際の作業順につながるようにする。
- 比較が中心なら表、まとまりの確認ならリストなど、内容に合う表現を選ぶ。数値は単位・桁・整列をそろえる。
- 主操作と補助操作を区別する。一括操作は対象件数と選択範囲を示す。
- 入力にはラベル、説明、エラー、送信中、完了の必要な状態を持たせる。
- 画面を狭くしたときも主要作業を保つ。表をスクロールする場合は、範囲と列の意味を把握できるようにする。
- クリック可能な部品には実際の操作を付ける。デモで未接続なら、そのことと可能な操作を表示する。

[状態設計](references/states.md) と [表示・操作](references/accessibility.md) を使って確認する。

## 検証

実データに近い日本語・数値、該当0件、大量データ、長い名称で確認する。検索やフィルタを実行し、結果件数・空状態・解除・キーボード操作を見る。

Light/Darkの両方で、フォーカスとエラーを色だけに頼らず示す。頻繁な操作は応答を優先し、装飾的な待ち時間を加えない。
