# Huawei / Zepp / Xiaomi / HONOR

出典は [索引](guide-index.md) の `huawei-*`、`zepp-*`、`xiaomi-*`、`honor-*`。メーカーの国や名前から共通の実装方式を推定せず、販売地域・製品・OS・SDKを確認する。

## Huawei / HarmonyOS

公式wearable入門ではSmart WearableとLite Wearableを区別し、手首での短い操作やCrownを紹介している。電話側との継続も含めて体験を組み立てる。

詳細なwearable設計ページは今回の取得ではタイムアウトした。入門の内容は確認済みだが、詳細ページの余白・文字サイズ・部品仕様は未確認。実装時に対象のHarmonyOS資料を開き直す。OpenHarmonyや別メーカーの資料を、Huawei商用製品の仕様として代用しない。

## Zepp OS / Amazfit

アプリ向けの標準ジェスチャーを尊重し、既存のスワイプへ独自の意味を割り当てない。物理キー・Crownの有無は対象機種で確かめる。公開資料のv3+という範囲と、実際に採用するAPIレベルを照合する。

文字盤のガイドは時刻と主要情報の階層、欠けを避ける外周を重視する。その文字盤向けpx値は、アプリや他OSの寸法へ一般化しない。

screen-off表示は通常の文字盤と位置をそろえ、秒を表示せず、黒背景と必要な情報へ絞る。大きい塗りや装飾画像を避ける。これはZeppのscreen-off文字盤の指針であり、全Watchアプリに一律適用する規則ではない。

## Xiaomi Vela

公式multi-screenガイドは丸型・角型・カプセル型を扱う。形だけを変えるのではなく、各形状の情報量・安全な領域・操作の並べ方を変える。掲載される解像度は機種別のpx値として扱う。

VelaのQuick App向け資料を参照する。同じXiaomiブランドでもWear OS製品などへそのまま適用せず、先に搭載OSを特定する。

## HONOR

Theme Centerの概要では文字盤・AOD等の配布対象を確認できるが、今回の本文取得は検索インデックスで確認できた概要に限られ、詳細ページは描画できなかった。アプリ向けの包括的なHIGを取得済みとはしない。Huaweiとの互換性・部品寸法・新規アプリの公開可否はこの資料から推定しない。
