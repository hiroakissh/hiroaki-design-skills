# 比較・図表・出典

- 棒の長さで量を比べるグラフは原則0を基点にする。省略が必要なら理由と軸を明示し、誤解を避ける。
- 時間変化、量の比較、構成比など、問いに合う形式を選ぶ。異なる意味の指標を一つの尺度に混ぜない。
- ラベル・値・凡例または併記表を用意する。色だけで系列や良否を区別しない。
- 実在する資料は元ページへリンクし、必要な調査日・発行日・対象を記す。図表のデータと出典の対応が分かるようにする。
- サンプル用の架空データには、実在する調査の出典を付けない。仮説や次の検証を、確定した結果と区別する。
- 推奨案は条件を伴わせる。不確実性、少ない対象、欠測などの限界を見つけられる位置へ置く。
