# 固定依頼文: Webアプリ

進行中のプロジェクトを管理するWebアプリの一覧画面を設計してください。検索、絞り込み、状態・進捗の比較、詳細へ進む導線を示してください。

- 比較用の幅: 1200 CSS px。画像は全高を使う。モバイル確認は390 CSS px。
- 使用データ: `data.json` の架空データ。
- 現段階: Atmospheric Graphite v1.0のLight/Darkを適用したHTML。検索・絞り込み・選択・追加を操作できるようにする。
- 用途の確認観点: 狭い画面、検索・絞り込み、キーボード、空・大量データ、選択・一括操作。

通常のスキル変更では依頼文・データ・画像サイズを維持し、変更による違いを比較する。
