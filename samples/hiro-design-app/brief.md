# 固定依頼文: アプリ

プロジェクトを確認するモバイルアプリの「一覧」と「詳細」を設計してください。長い日本語のプロジェクト名、進行状況、次の作業を示し、主な操作を一つ明確にしてください。

- 比較用の幅: 1200 CSS px。2画面を並べ、画像は全高を使う。モバイル確認は390 CSS px。
- 使用データ: `data.json` の架空データ。
- 現段階: Atmospheric Graphite v1.0のLight/Darkを適用したブラウザ用UIプロトタイプ。ネイティブ実機検証は含めない。
- 用途の確認観点: 長い日本語、文字サイズ変更、空・読込・失敗状態、キーボード表示。

通常のスキル変更では依頼文・データ・画像サイズを維持し、変更による違いを比較する。
