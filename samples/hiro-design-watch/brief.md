# 固定依頼文: 手首で始める集中タイマー

`hiro-design-watch` を使い、短い確認と一つの主操作で使える集中タイマーを設計してください。初期設定は25分、表示する時刻は比較用に09:41、作業名は「資料の構成を考える」で固定します。

角型・丸型・縦長バンドで、主情報と操作の並べ方を変えてください。開始・中断・再開・完了、設定時間の変更、一目で確認する情報面、常時表示を確認できるブラウザ用プロトタイプにしてください。時間は自動では進めず、サンプルの外側の操作で5分ずつ進めます。

Light/Darkはサンプルページの外観です。時計内はOLED向けの暗い表示を使い、黒キャンバスをOSへの適応として明記します。単色表示も比較し、色だけで状態を区別しないでください。

常時表示では秒や作業名を見せず、主情報の位置を保ち、更新停止と操作できない状態が分かるようにします。実OSのAmbientの完全な再現とは扱わないでください。

比較条件: ページ幅1200 CSS pxでLight/Darkの実表示を保存。390 CSS pxでも確認。時計の描画寸法は形状比較のためのCSS pxであり、実機のpt・dp・pxとは対応を保証しません。
