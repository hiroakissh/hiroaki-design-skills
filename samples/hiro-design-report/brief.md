# 固定依頼文: 調査レポート

架空の3案を比較する調査レポートの要約ページを設計してください。結論、同じ条件での比較、根拠、制約を読み分けられる構成にしてください。

- 比較用の幅: 1200 CSS px。画像は全高を使う。モバイル確認は390 CSS px。
- 使用データ: `data.json` の架空データ。実際の調査として扱わず、実在する出典を捏造しない。
- 現段階: Atmospheric Graphite v1.0のLight/Darkを適用したHTML。PDFや文書ソフトの書き出し検証は今回の対象に含めない。
- 用途の確認観点: 結論と根拠の対応、単位、比較条件、出典、事実と推測、ページ分割。

通常のスキル変更では依頼文・データ・画像サイズを維持し、変更による違いを比較する。
